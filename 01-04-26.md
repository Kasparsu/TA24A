### 2. ⏭️ Bulma Pagination Component

The session's first major topic was replacing the simple Prev/Next buttons with **Bulma's proper pagination component** — the kind with numbered page buttons and ellipsis (`...`) for large page ranges.

The instructor noted there are 52 pages of Rick and Morty characters — clicking through one by one is not practical. A real pagination UI shows the current page, surrounding pages, and skips to ellipsis for ranges far away.

**🔗 Links shared in class:**
| Resource | Description |
|----------|-------------|
| [Bulma Pagination](https://bulma.io/documentation/components/pagination/) | Full pagination component with numbered buttons, ellipsis, and previous/next |

**How Bulma's pagination structure works:**
- A `<nav class="pagination">` wrapper with Previous and Next links
- A `<ul class="pagination-list">` containing individual `<li>` elements
- Each item is either a `pagination-link` (numbered page), a `pagination-ellipsis` (the `...`), or marked as `is-current` for the active page
- The ellipsis (`...`) items use `v-if` to show conditionally based on the distance from the current page

### 3. 🧮 Vue `computed()` — Reactive Derived Values

To power the pagination logic, the session introduced **`computed()`** — one of Vue 3's most important Composition API features.

**What `computed()` does:**
- Takes a function and returns a reactive value derived from other reactive state
- Automatically recalculates whenever its dependencies change — you don't call it manually
- Read-only by default (you return a value, not mutate one)

**Why it was needed here:**
The pagination list (which page numbers to show, where to place ellipsis) depends on `currentPage` and `totalPages`. Rather than recalculating this inline in the template or manually in every function, a `computed()` value does it automatically whenever either dependency changes.

```js
import { ref, computed } from 'vue'

const currentPage = ref(1)
const totalPages = ref(52)

const pages = computed(() => {
  const result = []
  for (let i = 1; i <= totalPages.value; i++) {
    result.push(i)
  }
  return result
})
```

**Key concept — `+1` vs `++`:**
Inside a `computed()`, you must not mutate state directly — use `+ 1` / `- 1` instead of `++` / `--` to return a new value rather than modify the original.

### 6. 🔢 Pagination Logic — `v-if` for Ellipsis

The most complex part of the session was the **ellipsis logic** for the pagination component. The goal: show page numbers near the start, current page, and end — replacing the middle range with `...`.

The pattern covered:
- Always show page 1 and the last page
- Show pages within a window of ±2 around the current page
- Show `...` when there's a gap between the window and the edges
- Use `v-if` / `v-else-if` on `<li>` elements to conditionally render either a `pagination-link`, a `pagination-ellipsis`, or nothing
- Mark the current page with `is-current` class: `:class="{ 'is-current': page === currentPage }"`
- Clicking a page button calls a `goToPage(page)` function that updates `currentPage` and re-fetches

The instructor worked through the logic iteratively — using Vue DevTools to inspect computed values at each step and adjusting the `if` conditions by trial and error until the ellipsis appeared only in the right places.
