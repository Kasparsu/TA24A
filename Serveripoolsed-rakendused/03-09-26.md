### 2. 🔢 Types & `var_dump()`

A variable is written with a `$`, takes no keyword, and can hold anything:

```php
$test = 10;                              // int
$test = 3.1;                             // float
$test = 'Hello world!';                  // string
$test = 'õpilane';                       // Estonian characters are fine
$test = '💩';                            // so are emoji
$test = true;                            // bool
$test = false;
$test = null;                            // deliberately nothing
$test = [1, null, true, 'lol', 2, 3.2];  // array, mixed types allowed
$test = new stdClass();                  // a generic object
$test->name = 'Kaspar';                  // -> reaches a property
var_dump($test);
```

**`var_dump()` is the tool to reach for.** `echo` prints a value; `var_dump()` prints the value
**and its type** — and for strings, the length. When something behaves oddly, this is how you
find out what you're actually holding.

### 4. ➗ Arithmetic

```php
$test = 10 + 10;
$test = 10 - 10;
$test = 10 * 10;
$test = 10 / 10;
$test = 2 ** 3;    // exponent: 8
$test = 5 % 2;     // modulo (remainder): 1
```

**`%` is not a percent sign** — it's the remainder after division. `$n % 2` is the standard
even/odd test, and a remainder of `0` means it divides evenly.

**Compound assignment** — shorthand for "operate on the current value and store it back":
```php
$test += 3;   // same as $test = $test + 3
$test -= 3;
$test *= 3;
$test /= 3;
$test %= 3;
$test **= 3;
```

**Increment and decrement, in two flavours:**
```php
$test++;    // post-increment
$test--;
++$test;    // pre-increment
--$test;
```

**The difference matters when you use the result:**
```php
$a = 1;
$b = ++$a;
var_dump($b, $a);   // both 2 — incremented first, then read
```
`++$a` increments **then** returns; `$a++` returns the old value **then** increments. On its
own line they're identical; inside a larger expression they aren't.

**Anything beyond arithmetic is a function:**
```php
$test = sin(pi());
var_dump($test);
```
Note that the answer isn't exactly `0` — floating-point arithmetic is approximate, which is
worth remembering before you ever compare floats with `===`.

### 5. 🔤 Strings

```php
$test = 'yolo';
$test = 'yolo' . 'life';    // . joins strings, not +
$test = $test . 'thug';
$test .= 'life';            // compound form
```

**Building a sentence, two ways:**
```php
$name = 'Kaspar';
$age  = 33;

$test = $name . ' is ' . $age . ' years old!';   // concatenation
$test = "$name is $age years old!";              // interpolation — double quotes
$test = '$name is $age years old!';              // literal — single quotes, no substitution
```

**That's the whole difference between the quote types:**

| Quotes | Variables | Escapes |
|---|---|---|
| `'single'` | Literal text | Only `\'` and `\\` |
| `"double"` | **Interpolated** | `\n`, `\t`, … work |

```php
$test = 'don\'t';     // escape a quote with a backslash
$test = "lol\nlol\n"; // \n is a newline — double quotes only
```

## ✅ Takeaways

1. **Every variable starts with `$`** — no `let`, no `const`.
2. **`var_dump()` shows the type, `echo` doesn't.**
3. **`%` is remainder**, and `$n % 2` is the even/odd test.
4. **`++$a` and `$a++` differ** the moment you use the result.
5. **`.` joins strings.** Single quotes are literal, double quotes interpolate and honour `\n`.
6. **Floats are approximate** — `sin(pi())` isn't exactly zero.
