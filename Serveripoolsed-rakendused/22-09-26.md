## 🗂️ Topics Covered

> 🧭 Last time the blog template was cut into partials. This time the content moves out of
> the markup, the project gets a real document root, and one URL stops meaning one file.

### 1. 🗃️ Content out of the template, into an array

`views/us.php` starts with data, not markup:

```php
$title = 'U.S';
$posts = [
  ['title' => 'Some U.S title 1', 'date' => 'January 1, 2021',
   'author' => 'Pets', 'body' => 'Some U.S content 1'],
  // ...
];
```

The partial then loops over whatever it was given:

```php
<?php foreach ($posts as $post): ?>
  <h2><?= $post['title'] ?></h2>
  <p><?= $post['body'] ?></p>
<?php endforeach; ?>
```

The point: `partials/posts.php` does not know whether it is rendering world news or U.S.
news. The **page** supplies the data, the **partial** supplies the shape. That is the
same split you already use with functions: one piece decides *what*, the other *how*.

### 2. 🛟 `isset` and a sensible default

If a page forgets to define `$posts`, the partial explodes. Guard it:

```php
<?php if (isset($posts)): ?>
  ...
<?php endif; ?>
```

or give it something harmless to fall back to:

```php
$posts = $posts ?? [];
```

`??` (null coalescing) reads as "this, or that if the first is missing". An empty array
still loops (zero times) so the page renders blank instead of crashing.

![isset](https://api.memegen.link/images/fry/Not_sure_if_$posts_is_empty/or_I_just_forgot_to_set_it.png)

### 3. 📂 `public/` as the document root

`index.php` moved into `public/`. Everything the browser is allowed to fetch lives there;
everything else (views, partials, later your classes) sits outside it.

```bash
php -S localhost:8000 -t public public/index.php
```

Anything not under the document root simply cannot be requested, no matter what URL
someone types. That is the whole security argument for the layout, and it costs nothing.

Docs: <https://www.php.net/manual/en/features.commandline.webserver.php>

### 4. 🚦 A simple router

Every request now lands in one file, which decides what to include:

```php
switch ($_SERVER['REQUEST_URI']) {
    case '/':
        include __DIR__ . '/../views/index.php';
        break;
    case '/us':
        include __DIR__ . '/../views/us.php';
        break;
    default:
        echo '404';
}
```

Two things worth noticing:

- The URL and the filename are now **independent**. `/us` does not have to mean `us.php`,
  and a visitor cannot guess your file layout from the address bar.
- `default:` is not optional. Without it an unknown URL renders a blank page, which is
  much harder to debug than a printed `404`.

![Router](https://api.memegen.link/images/bihw/A_switch_on_REQUEST__URI/But_it's_honest_work.png)

### 5. 🖼️ Letting real files through

The router would happily try to "route" a stylesheet. The guard at the top stops that:

```php
if (preg_match('/\.(?:png|jpg|jpeg|gif|css|js)$/', $_SERVER["REQUEST_URI"])) {
    return false;    // serve the requested resource as-is
}
```

`return false` is specific to the built-in dev server: it means *you* deal with this one.
Under a real web server this is Apache or nginx's job and the check disappears.

![Static files](https://api.memegen.link/images/exit/Keep_adding_cases_to_index.php/Split_it_into_a_router_later.png)

### 6. ✨ Argument unpacking

Mentioned in passing while writing `dump()`:

```php
function dump(...$values) {
    echo '<pre>';
    var_dump(...$values);
    echo '</pre>';
}
```

`...$values` collects any number of arguments into an array on the way **in**, and spreads
an array back into separate arguments on the way **out**. One helper, any number of things
to inspect.

RFC: <https://wiki.php.net/rfc/argument_unpacking>

## ✅ Takeaways

1. **Data belongs to the page, markup belongs to the partial.** That is what makes one
   `posts.php` serve every section.
2. **`isset` / `??`**: a missing variable should render an empty page, not a fatal error.
3. **`public/` is the document root.** If a file is not in it, the browser cannot ask for it.
4. **A router decouples URL from filename.** One entry point decides what to include.
5. **Always write the `default:` branch.** A visible 404 beats a silent blank page.
6. **`...$args`** packs arguments in and spreads them back out.
