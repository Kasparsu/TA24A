## 🗂️ Topics Covered

### 1. 📜 Multi-line Strings — Heredoc

```php
$test = <<<END
    $age $name
      a
     b
    c
\n
END;
```

**`<<<END`** opens a *heredoc*: everything up to the closing `END;` is one string, newlines and
indentation included. Variables are interpolated, exactly like double quotes.

Useful when you'd otherwise be gluing `\n` onto the end of every line — a block of HTML or a
long message.

> 📌 The closing marker must be on its own line. Its indentation sets how much leading
> whitespace gets stripped from every line.

### 2. ✅ Boolean Logic

```php
$test = true && false;   // AND
$test = true || false;   // OR
$test = !true;           // NOT
$test = (true && false) || false || (true && !false);
```

PHP also has **word forms**, which are not interchangeable:

```php
$test = true xor false;   // exclusive or — true when exactly one side is true
$test = true and false;
$test = true or  false;
```

> ⚠️ `and`/`or` have **lower precedence than `=`**, so `$x = true and false;` assigns `true`
> and then evaluates the `and`. Stick to `&&` and `||`; the word forms are a trap.

### 3. ⚖️ Comparison — and PHP's Type Juggling

```php
$test = 10 > 5;
$test = 10 < 5;
$test = 10 == 10;
$test = 10 <= 10;
$test = 10 >= 10;
```

**The pair that matters:**
```php
$test = 10 == '10';    // true  — loose, converts types first
$test = 10 === '10';   // false — strict, type must match too
$test = 10 != '10';    // false
$test = 10 !== '10';   // true
$test = 0 == false;    // true  — and this is where it gets dangerous
```

`0 == false` is true. So is `'' == false`, and a good deal else. PHP converts types before
comparing, and the rules are not obvious — there's a **whole manual page of tables** for it.

**Use `===` and `!==` unless you have a specific reason not to.**

| Link | What it is |
|---|---|
| <https://www.php.net/manual/en/types.comparisons.php> | The loose-comparison tables — worth a look, once |

### 4. 📚 Arrays

```php
$test = array(1, 2, 3);   // old syntax, still valid
$test = [1, 2, 3];        // modern, use this
```

**Nesting** — index twice:
```php
$test = [1, 'asdas', true, [1, 2, 3]];
var_dump($test[3][1]);   // 2
```

**Associative arrays**, mixing named and automatic keys:
```php
$test = [
    1,
    'name' => 'Kaspar',
    'age'  => 33,
    3,
    'aadsas',
    true,
    100 => 'lol',
    'troll',
];
var_dump($test['name']);
```
Named keys and automatic numbering coexist, and setting `100 =>` changes where the automatic
numbering picks up. `var_dump()` the whole array to see what you actually built.

**Modifying:**
```php
array_push($test, 'added', 'zxvxxzcv', 3);  // push several at once
$test[] = 'new value';                      // shorthand for one
$test['name'] = 'Martin';                   // overwrite by key
$test[1] = 99999;                           // overwrite by index
unset($test[3]);                            // remove an element entirely
```

> 💡 `unset()` removes the key — it does **not** renumber the rest. The array ends up with a
> gap, which is fine but surprising if you assumed indexes stay contiguous.

### 5. 🔀 `if` / `elseif` / `switch`

```php
$num = 10;

if ($num > 10) {
    var_dump('Bigger');
} else if ($num < 10) {
    var_dump('Smaller');
} else {
    var_dump('Equal');
}
```

**A practical example — what day is it:**
```php
$day = (int) date('w');      // cast the string to an int
$day = intval(date('w'));    // the function form, same result
var_dump($day);

if ($day === 0) {
    var_dump('Sunday');
} elseif ($day === 1) {
    var_dump('Monday');
} elseif ($day === 5 || $day === 6) {
    var_dump('Partyday');
} else {
    var_dump('Weirdday');
}
```

Two new things: **`date('w')`** gives the weekday as a number, and **`(int)`** is a *cast* —
forcing a value to a type. `intval()` does the same thing as a function. Casting matters here
because `date()` returns a **string**, and `===` against a number would otherwise be false.

**The same logic as a `switch`:**
```php
switch ($day) {
    case 0:
        var_dump('Sunday');
        break;
    // …
    case 5:
    case 6:
        var_dump('Partyday');
        break;
    default:
        var_dump('Weirdday');
}
```

`case 5:` and `case 6:` stacked with no code between them is **deliberate fall-through** —
both run the same block. **Forgetting `break` elsewhere** lets execution run into the next
case, which is the classic `switch` bug.

### 6. 🔁 Loops

```php
for ($i = 0; $i < 10; $i++) { var_dump($i); }   // up
for ($i = 9; $i > 0; $i--)  { var_dump($i); }   // down
for ($i = 2; $i < 1_000_000; $i *= 2) { … }     // doubling
```

Three parts: **start; condition; step**. The step can be anything — `1_000_000` uses
underscores purely for readability.

**`while` — run until a condition stops holding:**
```php
$time = time();
$i = 0;
while (time() < $time + 1) {
    var_dump($i++);
}
```
Count iterations for one second. The number is much bigger than people expect — a useful sense
of how fast this actually is.

```php
while (false) { var_dump('WHILE'); }   // never runs

do {
    var_dump('DO');                    // runs once, then checks
} while (false);
```
**`while` tests before, `do…while` tests after** — so `do…while` always runs at least once.

```php
// while(true){
//
// }
```
Commented out deliberately: an infinite loop. `Ctrl+C` is how you escape one.

**`foreach` — the one you'll use for arrays:**
```php
$fruits = ['Apple', 'Banana', 'Cherry'];

foreach ($fruits as $fruit) {
    var_dump($fruit);
}

foreach ($fruits as $key => $fruit) {
    var_dump($key, $fruit);
    $fruit = 'asdads';       // ← does nothing to $fruits
}
var_dump($fruits);           // unchanged
```

**That last part is the lesson.** `$fruit` is a **copy**. Assigning to it inside the loop
changes the copy and leaves the array alone. (Modifying the original needs `as &$fruit` — a
reference, which is a later topic.)

## ✅ Takeaways

1. **Heredoc (`<<<END`)** for multi-line strings with interpolation.
2. **Use `&&`/`||`, not `and`/`or`** — the word forms have surprising precedence.
3. **`0 == false` is true.** Use `===`.
4. **`unset()` leaves a gap** rather than renumbering.
5. **Cast with `(int)` or `intval()`** — `date()` gives you a string.
6. **`switch` needs `break`**; stacked cases are the exception.
7. **`foreach` gives you a copy.** Assigning to the loop variable changes nothing.
