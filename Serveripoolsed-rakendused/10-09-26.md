## 🗂️ Topics Covered

### 1. 🧩 Functions

A named block of code you can run whenever you like:

```php
function hello(): void {
    var_dump('Hello');
}

var_dump(hello());   // NULL: it printed, but returned nothing
hello();
hello();
```

**`: void`** is the return type: this one promises to give nothing back. Printing and
returning are different things, and `var_dump(hello())` proves it.

**Parameters with defaults:**
```php
function helloName($name = 'Nameless', $age = 'unknown') {
    var_dump("Hello, $name! You are $age years old!");
}

helloName('Kaspar', 33);
helloName('Martin', 67);
helloName();            // both defaults used
```

Arguments match **by position**. A default makes an argument optional.

**Returning a value:**
```php
function square(int $a): int {
    if ($a < 0) {
        return 0;
    }
    return $a * $a;
}

$answer = square(2);
var_dump($answer);
var_dump(square(4));
```

`int $a` and `: int` are **type declarations**: PHP will complain if you pass or return the
wrong thing. The early `return 0` leaves immediately; nothing after a `return` runs.

### 2. 🔄 Recursion

```php
function recursion($i) {
    if ($i < 10) {
        var_dump($i);
        recursion($i + 1);
    }
}

recursion(0);
```

**A function calling itself.** Each call gets its own `$i`, one higher than the last, and the
chain unwinds when the condition finally fails.

> ⚠️ The `if` is not optional. **Remove the stopping condition and it calls itself forever**
> until PHP runs out of stack. Every recursive function needs a case where it *doesn't* recurse.

### 3. 🎭 Anonymous Functions & Callbacks

Functions don't need names: they're values:

```php
$test = function () {
    var_dump('Shh');
};

var_dump($test);        // object(Closure)
$test();                // call it directly
call_user_func($test);  // or call it by handle
```

**Where that's actually useful**: passing behaviour into another function:

```php
$numbers = [1, 2, 3, 4, 5];

$squares = array_map(function ($n) {
    return $n * $n;
}, $numbers);
var_dump($squares);

$squares = array_map(fn ($n) => $n * $n, $numbers);   // arrow function, same thing
var_dump($squares);
```

`array_map` runs your function over every element and returns a new array. The `fn () =>`
form implies the `return`, so a one-expression callback fits on one line.

### 4. 📦 Classes & Objects

```php
class Box {
    public $width;
    public $height;
    public $length;
    public $isOpen = false;
    public $hasBeenOpened = false;

    public function open() {
        $this->isOpen = true;
    }
}
```

A **class** is a template; an **object** is a thing made from it. Properties are its variables,
methods are its functions, `$this` is "the object this method was called on", and `->` reaches
inside.

```php
$box1 = new Box();
$box1->width = 10;
$box1->height = 10;
$box1->length = 10;
$box1->open();
var_dump($box1);

$box2 = new Box();
$box2->width = 20;
// …
$box2->open();
var_dump($box2);
var_dump($box1);   // untouched by anything box2 did
```

**One class, two independent objects.** Each has its own copy of every property.

### 5. 🔗 References, `clone`, and Modifying Arrays In Place

**`&` makes two names for one value:**
```php
$num1 = 1;
$num2 = &$num1;
$num1 = 2;
var_dump($num1, $num2);   // 2 and 2
```

**Objects behave that way by default**, which is why `clone` exists:
```php
$box1->width = 1;
$box2 = clone $box1;
$box1->width = 2;
var_dump($box1, $box2);   // 2 and 1: genuinely separate
```
Plain `$box2 = $box1` would give two names for *one* box. Simple values copy; objects don't.

**And this is what makes the `foreach` copy problem fixable:**
```php
$numbers = [1, 2, 3, 4, 5];

for ($i = 0; $i < count($numbers); $i++) {
    $n = &$numbers[$i];   // reference into the array
    $n += 1;
}

foreach ($numbers as &$n) {   // same idea, much shorter
    $n += 1;
}
var_dump($numbers);
```

**`as &$n`** hands you the actual element rather than a copy, so assigning to `$n` changes the
array. Without the `&`, both loops would do nothing.

## ✅ Takeaways

1. **Printing ≠ returning.** A `void` function gives back `NULL`.
2. **Defaults make arguments optional**; arguments match by position.
3. **Recursion needs a base case**, or it never stops.
4. **Functions are values**: pass them to `array_map`, shorten with `fn () =>`.
5. **Each object has its own properties**; `$this` is the one you called the method on.
6. **`&` shares, `clone` separates.** Objects share by default, scalars don't.
7. **`foreach ($a as &$n)`** is how you actually modify an array while looping it.
