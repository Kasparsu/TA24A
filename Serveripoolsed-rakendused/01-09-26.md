### 1. 💻 Installing the Toolchain with `winget`

Windows ships PowerShell but no Bash-style shell, and later server work assumes one. Rather
than downloading installers and clicking through wizards, everything goes through **winget**.

**Visual Studio Code:**
```powershell
winget install vscode
```
It asks once for permission to install from the Microsoft Store — accept, and it won't ask
again for that account.

**Git, interactively:**
```powershell
winget install --interactive Git.Git
```

The `--interactive` flag matters, because several Git install options can't be changed later:

| Option | Set to | Why |
|---|---|---|
| Default editor | **VS Code** | The default is Vim, and getting out of Vim is its own lesson |
| **Git Bash profile in Windows Terminal** | ✅ | **Cannot be added afterwards** |
| Default branch name | **`main`** | Matches what GitHub and everyone else now uses |

> ⚠️ Installed it already without those? `--force` reinstalls and lets you pick again — no need
> to uninstall.

Close and reopen the terminal afterwards, then set Git Bash as the default profile so new tabs
open in Bash instead of PowerShell.

**On the editor setting**, GitHub documents how the association works if you want to change it
later or use something else.

| Link | What it is |
|---|---|
| <https://docs.github.com/en/get-started/git-basics/associating-text-editors-with-git> | Associating a text editor with Git |

### 2. ⚙️ Configuring Git

```bash
git config --global user.name "Kaspar Martin Suursalu"
git config --global user.email "you@example.com"
```

**Per machine, not per project**, and **not a login** — it only decides what name and address
get stamped on your commits. Run it once on every computer you work on.

**Use the email your GitHub account knows**, so GitHub can link commits to your profile.
Nothing breaks if it doesn't match; your commits just won't be attributed.

> 🎓 Add a **personal** email address to your GitHub account too. GitHub supports several, and
> your school address stops working after you graduate — if it's the only one, you lose the
> account and the password reset with it.
