## 🗂️ Topics Covered

### 1. 🏗️ `__construct` and Constructor Property Promotion

```php
public function __construct(public $width, public $height, public $length) {
    var_dump('Object Created');
}
```

A **constructor** runs automatically when the object is created. Declaring the parameters as
`public $width` does three things at once: declares the property, sets its visibility, and
assigns it. The longhand would be a separate `public $width;` plus `$this->width = $width;`.

---

### 2. ✨ Magic Methods

Methods whose names start with `__` are called by PHP itself when something particular happens:

```php
public function __call($name, $args)  { var_dump($name, $args); }
public function __set($name, $value)  { var_dump($name, $value); }
public function __get($name)          { var_dump($name); return 'cool value'; }
public function __invoke()            { var_dump('I am a function'); }
public function __toString()          { return 'Im a Box'; }
public function __destruct()          { var_dump('Object destroyed'); }
```

**Each one demonstrated by using the object the "wrong" way:**

```php
$box1 = new Box(1, 2, 3);
echo $box1;                    // __toString  -> "Im a Box"
$box1->meow = 'lol';           // __set       -> property that doesn't exist
var_dump($box1->coolio);       // __get       -> "cool value"
$box1();                       // __invoke    -> calling the object itself
$box1->hello(1, 'asdasd');     // __call      -> method that doesn't exist
```

**And object lifetime:**

```php
function test() {
    $box2 = new Box(1, 2, 3);
}
test();     // created, then destroyed the moment the function ends
```

An object is destroyed when nothing refers to it any more: here, as soon as `test()` returns.
`__destruct` is what makes that visible.

### 3. 👪 Inheritance

```php
class MetalBox extends Box {
    public $weightPerUnit;

    public function mass() {
        return $this->weightPerUnit * $this->volume();
    }
}

$metal1 = new MetalBox(1, 2, 3);
$metal1->weightPerUnit = 1;
var_dump($metal1->mass(), $metal1);
```

`MetalBox` gets everything from `Box` and adds its own. Note `mass()` calling
`$this->volume()`: a method it inherited, used as if it were its own. The constructor is
inherited too, which is why `new MetalBox(1, 2, 3)` works without redeclaring it.

### 4. 🧵 Traits

```php
trait HasColor {
    public $color;
    public function showColor() {
        return $this->color;
    }
}

trait HasSmell {
    public $smell;
    public function sniff() {
        return $this->smell;
    }
}

class Box {
    use HasColor, HasSmell;
}
```

Inheritance gives a class **one** parent. A **trait** is a block of properties and methods
pasted into whichever class `use`s it, and a class can `use` **several**.

> 💡 Rule of thumb: `extends` for "is a kind of", traits for "can also do this".

### 5. 🔒 Visibility

```php
class Box {
    public bool $isOpen = false;
    private bool $hasBeenOpened = false;

    public function __construct(private int $width, private $height, private $length) { }

    public function setWidth(int $width) {
        if ($width < 0) {
            $this->width = 0;
        }
        $this->width = $width;
    }

    public function getWidth() {
        return $this->width;
    }

    public function test1() { var_dump($this->hasBeenOpened); }
    public function test2() { var_dump($this->hasBeenOpened); }
}
```

| Keyword | Reachable from |
|---|---|
| `public` | Anywhere |
| `private` | **Only the class that declared it** |
| `protected` | That class and its subclasses |

Properties are **typed** here (`public bool $isOpen`, `private int $width`), and the
constructor promotes its parameters as `private`.

**The point of hiding a property** is that you then control how it changes. `$width` is
private, so the only way in is `setWidth()`, which rejects a negative value. A public property
can be set to anything by anyone:

```php
$metal1->isOpen = 'asdasd';      // a string into a `bool` property
var_dump($metal1->isOpen);
```

**And the experiment at the end:**

```php
$metal1->test1();
$metal1->test2();
var_dump($metal1->hasBeenOpened);   // from outside, not allowed
```

`test1()` and `test2()` read `$hasBeenOpened` from **inside** the class, which is fine.
Reading it from outside is not. That contrast is the whole lesson about `private`.

## ✅ Takeaways

1. **`__construct(public $width)`** declares, sets visibility and assigns in one line.
2. **Magic methods fire on events**: missing property, missing method, string conversion,
   calling the object, destruction.
3. **An object dies when nothing refers to it**: leaving a function is enough.
4. **`extends` gives one parent**, and the child inherits the constructor too.
5. **Traits share behaviour across unrelated classes**, and you can use several.
6. **`private` + a setter lets you validate.** A public property can be set to anything,
   including the wrong type.
