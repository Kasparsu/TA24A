### 1. 🛠️ Work on the cinema project

The class worked on the cinema project's open task, *Kinoprojekt: andmebaasi struktuur ja
backendi valik* (due **01.10**), set in the previous lesson:

1. **`project.sql`**: the cinema database with sensible data types, primary keys, foreign

The background for both (constraints, driver vs ORM vs framework, migrations) is in the
[24.09 summary](24-09-26.md). Example code for the subject lives in
