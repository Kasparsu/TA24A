## 🗂️ Topics Covered

### 1. 🔌 Letting a Desktop Client Reach the Database

Adminer (from the previous session) runs *inside* the compose network, so it can reach the
database by service name. A program on **your** machine cannot — the database port isn't
exposed to the host at all.

One line fixes it:

```yaml
  db:
    image: mariadb
    restart: always
    environment:
      MARIADB_ROOT_PASSWORD: example
    ports:
      - 33061:3306
    volumes:
      - ta24alearndbdata:/var/lib/mysql
```

**`33061:3306`** — MariaDB listens on **3306** inside the container, and that's published as
**33061** on your machine.

> 💡 Why not just `3306:3306`? Because if you ever have a MySQL or MariaDB installed locally,
> or a second project running, they'd collide. The host-side number is yours to choose — pick
> something unlikely to clash.

**So the client connects to:**

| Setting | Value |
|---|---|
| Host | `localhost` |
| Port | `33061` |
| User | `root` |
| Password | `example` (the `MARIADB_ROOT_PASSWORD` set in compose) |

### 2. 🖥️ Database Clients

Adminer is fine for quick pokes — one small container, works in a browser. For real work
you'll want a proper client.

| Tool | Notes |
|---|---|
| **MySQL Workbench** | Free. Not the prettiest, does the job. |
| **DBeaver** | Free, better looking, supports many database systems |
| **DataGrip** (JetBrains) | The instructor's preference. **Now free for non-commercial use** — fine while it isn't a business |
| **VS Code extensions** | Exist, and you install a driver per database. Workable, but half-baked compared to a dedicated tool |

> 🎓 **JetBrains tools are free for students.** Worth claiming while you qualify — that covers
> DataGrip and the rest of the suite.

A general point: this space used to mean paying for anything good. Much of it has since gone
free, at least for non-commercial use, so check before assuming you need a licence.

## ✅ Takeaways

1. **A container's port is invisible to your machine until you publish it** with `ports:`.
2. **Pick a non-standard host port** (`33061`) to avoid clashing with anything local.
3. **Adminer for a quick look, a desktop client for real work** — DBeaver or DataGrip.
4. **Claim the student licences** while you're eligible.
